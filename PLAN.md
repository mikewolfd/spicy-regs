## How to run anything

Run every tool through `uv run`, never a bare `ruff`, `ty` or `pytest` from `PATH`: an older one
gives advice the pinned version rejects. Check `uv` itself the same way. On the maintainer's Mac the
`uv` first on `PATH` is an old pyenv shim and the current one is `/opt/homebrew/bin/uv`; use the
current one wherever the lines below say `uv`.

```bash
uv run --frozen --extra comments-reader ruff check .
uv run --frozen --extra comments-reader ty check
uv run --frozen --extra comments-reader pytest tests/test_<area>.py   # hosted CI runs the full suite
uv run --frozen spicy-regs-dict check      # descriptions vs schema
uv run --frozen spicy-regs-dict generate   # rewrites docs/tables/*.md AND the catalog and its digest
```

## Traps that have cost time here

- **If you can state it without running it, you have not checked it.** Every wrong call in this lane
  came from reasoning about a shape; every correct one from executed output. `except OSError` catches
  no DuckDB read error. A matching identifier *shape* is not a matching namespace.
- **A record that a fix was applied is not a check that it worked.** Re-observe the thing. Applied,
  armed and scheduled are three different words.
- **Audit documents against your own recent changes first**, not only against the world.
- **`grep` exits 1 on zero matches** and will silently break an `&&` chain that ends in a commit.
  `set -o pipefail`; zsh does not word-split unquoted `$var`.
- **State the population before quoting a rate**, and state a scan's reach: "clean everywhere I could
  reach" is a measurement, "clean" is a reassurance.
- **A file under `docs/` can hold R2 data alive.** The weekly retention job keeps every generation
  whose digest is prefixed by eight or more hex digits anywhere in a `.md` or `.json` file under
  `docs/` (`generation_retention.py`). Deleting or rewriting such a file releases the generation at
  the next Sunday run.
