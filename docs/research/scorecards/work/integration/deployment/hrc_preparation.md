The publisher index was captured separately and still links to that PDF. These are publisher reads; no congressional source is reacquired.

The helper reads a frozen current publication index and fetches every prior source table by immutable pin. After the production scope merge, it compares every unselected row exactly, including existing source locators and observation identifiers.
